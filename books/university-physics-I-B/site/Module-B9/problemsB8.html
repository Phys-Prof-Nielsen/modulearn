Problem B8.1

A 0.2-kg particle is travelling in the xy-plane along the line y = 2.0 m with a velocity 5.0 m/s. What is the angular momentum of the particle about the origin when x = 5.0 m?

This problem is a slightly modified version from OpenStax. Access for free at https://openstax.org/books/university-physics-volume-1/pages/11-problems

# DIY Cell

Show code cell source

Hide code cell source

 
%reset -f

import numpy as np

# use l = r x p = rpsin(theta)
# p is the linear momentum: px = m*vx
# r is the directed line segment from origin to the particle's location at that instant.

m = 0.2
v = 5.0
y = 2.0
x = 5.0

#magnitude of vector r
r = np.sqrt(x**2 + y**2)
#magnitude of momentum vector
p = m*v

#angle between r and p vectors
theta = np.arctan(y/x)

l = r*p*np.sin(theta)

print('Magnitude of angular momentum: '+str(l))

#direction from RHR: negative z-direction
print('Direction: negative z-direction')

Problem B8.6

The Sun’s mass is \(2.0\times 10^{30}\) kg, its radius is \(7.0\times 10^5\) km, and it has a rotational period of approximately 28 days. If the Sun should collapse into a white dwarf of radius \(3.5\times 10^3\) km, what would its period be if no mass were ejected and a sphere of uniform density can model the Sun both before and after? In this problem, assume the angular momentum is the same before and after the collapse.

This problem is a slightly modified version from OpenStax. Access for free.

# DIY Cell

Hide code cell source

 
%reset -f

import sympy as sp

M1 = 2.0e30
R1 = 7.0e8
T1 = 28

I1 = (2/5)*M1*R1**2

M2 = M1
R2 = 3.5e6
T2 = sp.Symbol('T2')

I2 = (2.5)*M2*R2**2

#conservation of angular momentum
L1 = I1*(2*sp.pi/T1)  #Omega = 2*pi/T
L2 = I2*(2*sp.pi/T2)

eq = L2 - L1
sol = sp.solve(eq,T2)

T2 = sol[0]
print('Period in days: '+str(T2))

T_sec = float(T2)*3600 # period in seconds
print('Period in seconds: '+str(T_sec))

Problem B8.7

A ride at a carnival has four spokes to which pods are attached that can hold two people. The spokes are each 15 m long and are attached to a central axis. Each spoke has mass 200.0 kg, and the pods each have mass 100.0 kg. If the ride spins at 0.2 rev/s with each pod containing two 50.0 kg children, what is the new spin rate if all the children jump off the ride? Assumen the kids can be considered as point masses, and assume the angular momentum is the same before and after the kids jump off.

This problem is a slightly modified version from OpenStax. Access for free.

# DIY Cell

Show code cell source

Hide code cell source

 
%reset -f

import sympy as sp

#spokes
Ls = 15.0
Ms = 200.0

Is = (1/3)*Ms*Ls**2

#Pods
Mp = 100.0
Rp = 15.0

Ip = Mp*Rp**2

#children
Mc = 50.0
Rc = 15.0

Ic = Mc*Rc**2

I1 = 4*Is + 4*Ip + 8*Ic
I2 = 4*Is + 4*Ip

Omega1 = 0.2  #in rev/s

#conservation of ang. momentum
Omega2 = sp.Symbol('Omega2')
eq = I2*Omega2 - I1*Omega1
sol = sp.solve(eq,Omega2)

print('New spin rate: '+str(sol[0])+' rev/s')

Problem B8.8

  1. Calculate the angular momentum of Earth in its orbit around the Sun.

  2. Compare this angular momentum with the angular momentum of Earth about its axis.

This problem is a slightly modified version from OpenStax. Access for free.

# DIY Cell

Show code cell source

Hide code cell source

 
%reset -f
import numpy as np

# center to center distance Sun-Earth: 1 AU = 1.496 x 10^11 m
# mass of earth: 5.972 x 10^24 kg
# radius of earth: 6.378 x 10^6 m

#-----------------
# PART 1
#-----------------
R = 1.496E11
M = 5.972E24
# Find the orbital angular momentum
# L = R x P = RPsin(theta) 
# theta = 90 degrees
# tangential speed: distance/time
D = 2*np.pi*R
T = (365)*(24)*(3600)  # (365 days)*(24 hrs/day)*(3600 s/1 hr)
V = D/T

L_o = R*M*V
print('Orbital angular momentum: '+str(L_o))

#-----------------
# PART 2
#-----------------
R_E = 6.378E6
M = 5.972E24
# Find the spin angular momentum
# L = I*Omega 
# Assume solid, uniform sphere
I = (2.0/5.0)*M*R_E**2
Omega = (1.0/24)*(2*np.pi)*(1.0/3600)  # (1 rev/24 hr)*(2 pi rad/ 1 rev)*(1 hr/ 3600 s)

L_s = I*Omega
print('Spin angular momentum: '+str(L_s))
