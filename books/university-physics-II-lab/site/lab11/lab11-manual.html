Lab 11: RC Circuits — Charging and Discharging with Arduino#

Overview#

In this lab, we investigate the time-dependent behavior of a resistor-capacitor (RC) circuit using an Arduino as both a control and measurement device. By charging and discharging a capacitor through a resistor, we will observe the characteristic exponential behavior of voltage and determine the time constant of the circuit.

This lab connects theory with real-world measurement, highlighting how circuits respond dynamically over time.

Learning Objectives#

By the end of this lab, we will be able to:

  1. Describe the charging and discharging behavior of a capacitor in an RC circuit.

  2. Measure voltage as a function of time using an Arduino.

  3. Determine the time constant \(\tau = RC\) experimentally.

  4. Fit exponential models to data and interpret the results physically.

  5. Compare experimental data with theoretical predictions.

Background Theory#

RC Charging#

When a capacitor charges through a resistor from a voltage source \(V_0\), the voltage across the capacitor evolves as:

\[ V_C(t) = V_0 \left(1 - e^{-t/RC} \right) \]

  • Initially: \(V_C(0) = 0\)

  • Long time: \(V_C \to V_0\)

RC Discharging#

When the capacitor discharges through the resistor:

\[ V_C(t) = V_0 e^{-t/RC} \]

  • Initially: \(V_C(0) = V_0\)

  • Long time: \(V_C \to 0\)

Time Constant#

The time constant is defined as:

\[ \tau = RC \]

  • Charging: \(V_C(\tau) \approx 0.63 V_0\)

  • Discharging: \(V_C(\tau) \approx 0.37 V_0\)

Linearization#

\[ \ln V_C(t) = \ln V_0 - \frac{t}{RC} \]

👉 A plot of \(\ln V_C\) vs. \(t\) gives slope \(-1/RC\)

Equipment#

  • Arduino (Uno or similar)

  • Breadboard

  • Resistor (\(1\,\text{k}\Omega\) – \(100\,\text{k}\Omega\))

  • Capacitor (\(10\,\mu\text{F}\) – \(1000\,\mu\text{F}\))

  • Jumper wires

  • Computer

Experimental Setup#

  • Connect resistor and capacitor in series

  • Arduino digital pin provides charging voltage

  • Analog pin measures capacitor voltage

Circuit Concept (ASCII)#

Arduino Pin (D8)
     |
     R
     |
     +------ A0 (measure VC)
     |
     C
     |
    GND

Experimental Procedure#

Part A — Charging/Discharging#

  1. Upload Arduino code

  2. Record analog values over time

  3. Convert to voltage:

\[ V = \frac{\text{analogRead}}{1023} \times 5.0 \]

  1. Start the Serial Monitor.

  2. First, voltage increases until it stabilizes. The program is set to stop recording the charging process after 1 s.

  3. Second, the voltage decrease until near zero. The program is set to stop recording the discharging process after 1 s.

  4. This process continues through a loop on the arduino.

Part B — Import Data#

  1. After 1 complete charging/discharging cycle (~2 seconds), unplug the Arduino.

  2. Copy-paste one complete cycle in to a data file.

  3. Analysize it using Excel, Python, or other favorite tool.

Data Analysis#

1. Plot \(V(t)\)#

Plot charging and discharging curves

2. Time Constant Estimate#

Find time where:

\[ V = 0.37 V_0 \]

3. Linearization#

Plot \(\ln V\) vs \(t\)

\[ \ln V = mt + b \]
\[ \tau = -\frac{1}{m} \]

4. Compare#

\[ \tau_{\text{theory}} = RC \]

Arduino Code Template#

const int chargePin = 8;
const int readPin = A0;

void setup() {
  Serial.begin(9600);
  pinMode(chargePin, OUTPUT);
}

void loop() {
  digitalWrite(chargePin, HIGH);
  for (int i = 0; i < 100; i++) {
    int val = analogRead(readPin);
    float voltage = val * (5.0 / 1023.0);
    float time = i * 0.01;
    Serial.print(time);
    Serial.print("\t");
    Serial.println(voltage);
    delay(10);
  }

  digitalWrite(chargePin, LOW);
  for (int i = 0; i < 100; i++) {
    int val = analogRead(readPin);
    float voltage = val * (5.0 / 1023.0);
    float time = i * 0.01;
    Serial.print(time);
    Serial.print("\t");
    Serial.println(voltage);
    delay(10);
  }
  delay(3000);
}

Python Analysis Template#

import numpy as np
import matplotlib.pyplot as plt

data = np.loadtxt("rc_data.csv", delimiter=",", skiprows=1)
t = data[:,0]
V = data[:,1]

plt.plot(t, V, 'o')
plt.xlabel("Time (s)")
plt.ylabel("Voltage (V)")
plt.show()

mask = V > 0
t_lin = t[mask]
V_lin = V[mask]

lnV = np.log(V_lin)
coeffs = np.polyfit(t_lin, lnV, 1)
m = coeffs[0]

tau = -1/m
print(tau)
