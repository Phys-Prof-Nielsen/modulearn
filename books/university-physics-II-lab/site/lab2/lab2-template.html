1. Abstract#

Write 100–150 words summarizing:

  • the purpose of the experiment (measuring LED forward voltage and quantifying uncertainty),

  • the measurement method (Arduino voltage measurements under fixed DC conditions),

  • the key statistical results (mean forward voltage and standard error of the mean), and

  • the main conclusion regarding measurement variability versus device-to-device variation.

2. Introduction#

  • Describe what a light-emitting diode (LED) is and explain the concept of forward bias.

  • Define the forward voltage \(V_f\) as the voltage drop across an LED when it is conducting.

  • Explain why \(V_f\) is expected to be approximately constant for a single LED under fixed conditions.

  • Distinguish between:

    • measurement variability (scatter in repeated measurements of one LED)

    • manufacturing variation (differences in \(V_f\) between LEDs)

  • State why repeated measurements and statistical analysis are required even when measuring a constant physical quantity.

  • Explain the role of the standard deviation and the standard error of the mean (SEM) in this experiment.

2. Methodology#

Briefly describe the experimental and computational workflow used in this lab.
(Include code cells where appropriate for transparency, but reserve analysis and interpretation for the Results section.)

  1. Assemble the LED circuit with a series resistor and fixed DC supply from the Arduino.

  2. Measure the LED forward voltage using a differential voltage measurement with two analog inputs.

  3. For each LED, record 20 repeated measurements of \(V_f\) while the LED remains continuously ON.

  4. Repeat the measurement process for multiple LEDs of the same type.

  5. Organize all raw voltage measurements into a single data table.

  6. Compute per-LED mean forward voltages and standard deviations.

  7. Compute the overall mean forward voltage and the standard error of the mean (SEM) across LEDs.

This section is where you present and analyze your data.
Numerical results, tables, plots, and calculated quantities belong here.

Organize this section so that the reader can clearly follow how raw measurements lead to the final reported result.

Your Results / Analysis section should include the following components, in a logical order:

Per-LED Analysis#

  • Compute the mean forward voltage for each LED using its 20 measurements.

  • Compute the sample standard deviation for each LED.

  • Present these values in a clearly labeled table.

This part addresses measurement variability for a single LED.

# Example script
import numpy as np

# Example: forward-voltage measurements for one LED (in volts)
Vf = np.array([1.98, 2.01, 1.99, 2.00, 1.97])

# Number of measurements
n = len(Vf)

# Mean forward voltage
Vf_mean = np.mean(Vf)

# Sample standard deviation (ddof=1 is essential!)
Vf_std = np.std(Vf, ddof=1)

print(f"Number of measurements: n = {n}")
print(f"Mean forward voltage: {Vf_mean:.3f} V")
print(f"Sample standard deviation: {Vf_std:.4f} V")

Uncertainty in the Mean#

  • Compute the standard error of the mean (SEM) using the standard deviation across LEDs and the number of LEDs measured.

  • Clearly indicate which quantity the SEM applies to.

# Example code
import numpy as np

# Mean forward voltage for each LED (in volts)
# Replace these example values with your measured LED means
Vf_means = np.array([
    1.98,   # LED 1
    2.01,   # LED 2
    1.99,   # LED 3
    2.00,   # LED 4
    1.97    # LED 5
])

# Number of LEDs
N = len(Vf_means)

# Overall mean forward voltage
Vf_mean = np.mean(Vf_means)

# Standard deviation across LEDs (sample standard deviation!)
Vf_std = np.std(Vf_means, ddof=1)

# Standard error of the mean
SEM = Vf_std / np.sqrt(N)

print(f"Number of LEDs: N = {N}")
print(f"Overall mean forward voltage: {Vf_mean:.3f} V")
print(f"Standard deviation across LEDs: {Vf_std:.4f} V")
print(f"Standard error of the mean (SEM): {SEM:.4f} V")
