D9.6 Problems — Index Notation Practice#

These problems help you practice translating familiar vector equations from standard vector notation into index notation using the Einstein summation convention.

Throughout these problems, assume that indices run over

\[ i = 1,2,3. \]

Problem 1: Translating Mechanics Equations into Index Notation#

Many equations from introductory physics involve vectors. Rewrite the following equations using index notation.

  1. Newton’s second law

\[ \mathbf{F} = m\mathbf{a} \]

  1. Momentum

\[ \mathbf{p} = m\mathbf{v} \]

  1. Dot product

\[ \mathbf{a}\cdot\mathbf{b} \]

  1. Kinetic energy

\[ T = \frac{1}{2} m v^2 \]

  1. Angular momentum

\[ \mathbf{L} = \mathbf{r}\times\mathbf{p} \]

  1. Torque

\[ \boldsymbol{\tau} = \mathbf{r}\times\mathbf{F} \]
Problem solution

  1. Newton’s second law

The vector equation represents three component equations. In index notation

\[ F_i = m a_i. \]

  1. Momentum

\[ p_i = m v_i. \]

  1. Dot product

\[ \mathbf{a}\cdot\mathbf{b} = a_i b_i. \]

  1. Kinetic energy

Since

\[ v^2 = \mathbf{v}\cdot\mathbf{v}, \]

we obtain

\[ T = \frac{1}{2} m v_i v_i. \]

  1. Angular momentum

Using the Levi–Civita symbol,

\[ L_i = \epsilon_{ijk} r_j p_k. \]

  1. Torque

Similarly,

\[ \tau_i = \epsilon_{ijk} r_j F_k. \]

Interpretation#

Index notation allows familiar vector equations to be written in a compact form that automatically represents all components simultaneously. This notation will become especially useful when working with rotational dynamics and tensor quantities later in the course.

Problem 2: Magnitudes and Dot Products#

Rewrite the following expressions using index notation.

  1. Magnitude squared of position

\[ r^2 = x^2 + y^2 + z^2 \]

  1. Speed squared

\[ v^2 = v_x^2 + v_y^2 + v_z^2 \]

  1. Work done by a constant force

\[ W = \mathbf{F}\cdot\Delta\mathbf{r} \]
Problem solution
\[ r^2 = r_i r_i \]
\[ v^2 = v_i v_i \]
\[ W = F_i \Delta r_i \]

Problem 3: Component Interpretation#

The indexed equation

\[ F_i = m a_i \]

represents three equations simultaneously.

  1. Write out the three equations explicitly using Cartesian components.

  2. Explain why index notation allows us to write all three equations using a single compact expression.

Problem solution

The free index \(i\) represents three separate equations:

For \(i=1\)

\[ F_1 = m a_1 \]

For \(i=2\)

\[ F_2 = m a_2 \]

For \(i=3\)

\[ F_3 = m a_3 \]

In Cartesian coordinates these correspond to

\[ F_x = m a_x \]
\[ F_y = m a_y \]
\[ F_z = m a_z. \]

Thus the indexed equation

\[ F_i = m a_i \]

represents all three component equations simultaneously.

Problem 4: Speed in Parabolic Coordinates Using Index Notation#

A particle moves in the plane. Its Cartesian coordinates are related to parabolic coordinates \((u,v)\) by

\[ x = uv \]
\[ y = \frac{1}{2}(u^2 - v^2). \]

Using index notation, determine an expression for the speed squared

\[ v_{\text{speed}}^2 \]

in terms of \(u\), \(v\), \(\dot u\), and \(\dot v\).

Problem solution

We use

\[ v_{\text{speed}}^2 = g_{jk}\dot q_j \dot q_k, \]

where

\[ g_{jk} = \frac{\partial x_i}{\partial q_j} \frac{\partial x_i}{\partial q_k}. \]

Here,

\[ q_1 = u, \qquad q_2 = v. \]

Step 1 — Compute partial derivatives

For

\[ x_1 = x = uv, \]
\[ \frac{\partial x}{\partial u} = v, \qquad \frac{\partial x}{\partial v} = u. \]

For

\[ x_2 = y = \frac{1}{2}(u^2-v^2), \]
\[ \frac{\partial y}{\partial u} = u, \qquad \frac{\partial y}{\partial v} = -v. \]

Step 2 — Compute metric components

\[ g_{uu} = \frac{\partial x_i}{\partial u} \frac{\partial x_i}{\partial u} = \frac{\partial x_1}{\partial u} \frac{\partial x_1}{\partial u} + \frac{\partial x_2}{\partial u} \frac{\partial x_2}{\partial u} \]
\[ g_{uu} = v^2 + u^2. \]
\[ g_{uv} = \frac{\partial x_i}{\partial u} \frac{\partial x_i}{\partial v} = \frac{\partial x_1}{\partial u} \frac{\partial x_1}{\partial v} + \frac{\partial x_2}{\partial u} \frac{\partial x_2}{\partial v} \]
\[ g_{uv} = (v)(u) + (u)(-v) = 0. \]

Similarly,

\[ g_{vv} = \frac{\partial x_i}{\partial v} \frac{\partial x_i}{\partial v} \]
\[ g_{vv} = u^2 + v^2. \]

Thus,

\[ g_{uu}=u^2+v^2, \qquad g_{uv}=0, \qquad g_{vv}=u^2+v^2. \]

Step 3 — Compute speed squared

Using

\[ v_{\text{speed}}^2 = g_{jk}\dot q_j\dot q_k, \]

we get

\[ v_{\text{speed}}^2 = g_{uu}\dot u^2 + 2g_{uv}\dot u\dot v + g_{vv}\dot v^2. \]

Since \(g_{uv}=0\),

\[ v_{\text{speed}}^2 = (u^2+v^2)\dot u^2 + (u^2+v^2)\dot v^2. \]

Therefore,

\[ \boxed{ v_{\text{speed}}^2 = (u^2+v^2)(\dot u^2+\dot v^2) } \]

and

\[ \boxed{ v_{\text{speed}} = \sqrt{(u^2+v^2)(\dot u^2+\dot v^2)} } \]

Interpretation

The metric tells us how coordinate changes in \((u,v)\) correspond to physical distance in the plane. Here the coordinates are orthogonal because

\[ g_{uv}=0. \]

Both coordinate directions have the same scale factor:

\[ h_u = h_v = \sqrt{u^2+v^2}. \]

Thus, motion in either coordinate direction contributes to speed through the same geometric factor.
