Problem C3.1

A 0.50 kg particle is intially traveling with a velocity of \(\vec{v} = (450~\textrm{m/s})\hat{i} + (25~\textrm{m/s})\hat{j} - (275~\textrm{m/s})\hat{k}\). After an interaction, the particle is traveling in the xy-plane with \(z = 0\) and with a speed of 455 m/s in a direction of 23\(^\circ\) clockwise from the -x-axis.

  1. What is the initial momentum of particle?

  2. What is the magnitude of the initial momentum?

  3. What are the x,y, and z momentum components of the particle after the interaction?

  4. What is the change in momemtum of the particle?

Show code cell source

Hide code cell source

 
%reset -f

import numpy as np

m = 0.50
vi = np.array([450, 25, -275])

speed_f = 455
theta = np.radians(23)  #clock-wise from -x axis --> 2nd quadrant

# Part 1
pi = m*vi

print('Initial momentum is '+str(pi)+' kgm/s')

# Part 2
p = np.sqrt(pi[0]**2 + pi[1]**2 + pi[2]**2)
print('Magnitude of initial momentum is '+str(p)+' kgm/s')

# Part 3
vfx = -speed_f*np.cos(theta)
vfy = speed_f*np.sin(theta)
vfz = 0

pf = m*np.array([vfx, vfy, vfz])
print('The final momentum components are '+str(pf)+' kgm/s')

# Part 4
dp = pf - pi
print('The change in momentum is '+str(dp)+' kgm/s')

Problem C3.3

A 0.25 kg particle is traveling (in the xy-plane) with an initial velocity (in m/s) of

\[\begin{split} \vec{v}_i = \begin{bmatrix} 75.0 \\ -63.0 \end{bmatrix} \end{split}\]

Sometime later, its velocity (in m/s) is

\[\begin{split} \vec{v}_f = \begin{bmatrix} 24.5 \\ 5.0 \end{bmatrix} \end{split}\]

What are the magnitudes and directions of the:

  1. the initial momentum?

  2. the final momentum?

  3. the change in momentum?

Show code cell source

Hide code cell source

 
%reset -f

import numpy as np

def magnitude(vec):
    return(np.sqrt(vec[0]**2 + vec[1]**2))

m = 0.25
vi = np.array([75.0, -63.0])
vf = np.array([24.5, 5.0])

# Part 1
pi = m*vi
pi_mag = magnitude(pi)
print('The initial momentum magnitude is '+str(pi_mag)+' kgm/s')

#pi is in 4th quadrant
angle = np.degrees(np.arctan(np.abs(pi[1]/pi[0])))
print('The direction is '+str(angle)+' CW from +x-axis')

print(' ')
# Part 2
pf = m*vf
pf_mag = magnitude(pf)
print('The final momentum magnitude is '+str(pf_mag)+' kgm/s')

#pf is in 1th quadrant
angle = np.degrees(np.arctan(np.abs(pf[1]/pf[0])))
print('The direction is '+str(angle)+' CCW from +x-axis')

print(' ')
# Part 3
dp = pf - pi
dp_mag = magnitude(dp)
print('The change in momentum magnitude is '+str(dp_mag)+' kgm/s')

#dp is in 2th quadrant
angle = np.degrees(np.arctan(np.abs(dp[1]/dp[0])))
print('The direction is '+str(angle)+' CW from -x-axis')

Problem C3.6

Air Hockey Collision: On an air hockey table, a 0.20 kg puck moving eastward at 5.0 m/s collides with a stationary 0.10 kg puck. After the collision, the first puck moves westward at 2.0 m/s. Calculate the final velocity of the second puck.

# DIY Cell

Show code cell source

Hide code cell source

 
%reset -f
import sympy as sym

m1 = 0.20
m2 = 0.10
v1i = 5.0
v1f = -2.0

v2f = sym.Symbol('v2f')

#conservation of momentum
# p1_i + p2_i = p1_f + p2_f

eq = m1*v1f + m2*v2f - m1*v1i

sol = sym.solve(eq)

print('The speed of the particle after the collision is '+str(sol[0])+' m/s')

Problem C3.7#

Pool Table Collision: On a pool table, a cue-ball (mass 0.17 kg) moving at 2.0 m/s in the east direction collides with a stationary 9-ball (mass 0.16 kg). After the collision, the cue-ball moves at an angle of 30.0 degrees north of east, while the 9-ball moves at an angle of 60.0 degrees south of east. Calculate the final speed of each ball.

# DIY Cell

Show code cell source

Hide code cell source

 
%reset -f

import sympy as sym
import numpy as np

m1 = 0.17
m2 = 0.16
v1i = 2.0
theta1 = np.radians(30.0)
theta2 = np.radians(60.0)

v1f = sym.Symbol('v1f')
v2f = sym.Symbol('v2f')

eq1 = m1*v1f*np.cos(theta1) + m2*v2f*np.cos(theta2) - m1*v1i
eq2 = m1*v1f*np.sin(theta1) - m2*v2f*np.sin(theta2)

sol = sym.solve((eq1,eq2),(v1f,v2f))

print('After the collision the cue moves at '+str(sol[v1f])+' m/s. The 9-ball moves at '+str(sol[v2f])+' m/s')

Problem C3.8#

Particle Collision in a Particle Accelerator
In a high-energy particle accelerator experiment, two protons, P1 and P2, with identical masses of \(1.67 \times 10^{-27}\) kg collides. P2 is accelerated towards towards P1. Initially, P1 is at rest, while P2 is moving with a velocity of 0.90\(c\) (where \(c\) is the speed of light) in the positive x-direction. They collide head-on and annihilate each other, producing two new particles, A and B. Particle A moves off at an angle of 60.0 degrees north of the x-axis with a speed of 0.60\(c\). Particle B moves off at an angle of 30.0 degrees south of the x-axis with a speed of 0.70\(c\).

  1. Calculate the total momentum of the system before the collision.

  2. Calculate the total momentum of the system after the collision.

  3. Determine the masses of particles A and B.

  4. Verify whether kinetic energy is conserved in this collision.

#DIY Cell

Show code cell source

Hide code cell source

 
%reset -f

import numpy as np
import sympy as sym

# Let +x be in direction of initial motion of P2
m1 = 1.67E-27
m2 = 1.67E-27
v1x = 0.0
v1y = 0.0
c = 2.998E8
v2x = 0.9*c
v2y = 0.0

# Part 1
Pix = m1*v1x + m2*v2x
Piy = m1*v1y + m2*v2y
Pi = np.array([Pix, Piy])
print('Inital momentum is '+str(Pi)+' kgm/s')
print(' ')

# Part 2
Pf = Pi
print('Since momentum is conserved the momentum after the collision is '+str(Pf)+' kgm/s')
print(' ')

# Part 3
vA = 0.60*c
vB = 0.70*c

thetaA = np.radians(60.0)
thetaB = np.radians(30.0)

mA = sym.Symbol('mA')
mB = sym.Symbol('mB')

#conservation of momentum: 0 = Pf - Pi
eqx = mA*vA*np.cos(thetaA) + mB*vB*np.cos(thetaB) - Pix
eqy = mA*vA*np.sin(thetaA) - mB*vB*np.sin(thetaB) - Piy

sol = sym.solve((eqx,eqy),(mA,mB))
mA = sol[mA]
mB = sol[mB]

print('Mass A is '+str(mA)+' kg, and mass B is '+str(mB)+' kg')
print(' ')

#Part 4
v1 = np.sqrt(v1x**2 + v1y**2)
v2 = np.sqrt(v2x**2 + v2y**2)
Ki = 0.5*m1*v1**2 + 0.5*m2*v2**2
Kf = 0.5*mA*vA**2 + 0.5*mB*vB**2
dK = Kf - Ki
if dK == 0:
    print('Change in kinetic energy: '+str(dK)+' J')
    print('Kinetic energy is conserved')
else:
    print('Change in kinetic energy: '+str(dK)+' J')
    print('Kinetic energy is not conserved')
