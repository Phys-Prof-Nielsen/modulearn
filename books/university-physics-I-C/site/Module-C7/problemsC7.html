Problem C7.2

Two particles of masses \(m_1\) and \(m_2\) move uniformly in different circles of radii \(R_1\) and \(R_2\) about the origin in the \(x\), \(y\)-plane. The coordinates of the two particles in meters are given as follows (\(z = 0\) for both). Here \(t\) is in seconds:

\[\begin{align*} x_{1}(t) &= \,4\cos(2t) \\ y_{1}(t) &= \,4\sin(2t) \\ x_{2}(t) &= \,2\cos\left(3t - \frac{\pi}{2}\right) \\ y_{2}(t) &= \,2\sin\left(3t - \frac{\pi}{2}\right) \\ \end{align*}\]

  1. Find the radii of the circles of motion of both particles.

  2. Find the x- and y-coordinates of the center of mass. Express the solution as a function of time and the two masses.

  3. Decide if the center of mass moves in a circle by plotting its trajectory.

Problem C7.3 CM Pseudo Work–Energy vs System Work–Energy#

Two low-friction carts move along a horizontal, frictionless track and stick together in a perfectly inelastic collision. There are no horizontal external forces (ignore air drag).

  • Cart 1: mass \(m_1 = 1.0~\text{kg}\), initial velocity \(+3.0~\text{m/s}\)

  • Cart 2: mass \(m_2 = 2.0~\text{kg}\), initial velocity \(-1.0~\text{m/s}\) (toward cart 1)

After the collision, the joined carts move together with speed \(v_f\).

Answer the following:

  1. Compute the center-of-mass velocity \(V_{\text{cm}}\) before the collision. What is \(V_{\text{cm}}\) after the collision?

  2. Using the CM pseudo work–energy theorem \(W_{\text{ext}}^{(\text{cm})}=\Delta K_{\text{cm}}\), find \(\Delta K_{\text{cm}}\) for the collision. Explain briefly.

  3. Compute the total kinetic energy before and after the collision, \(K_{\text{tot},i}\) and \(K_{\text{tot},f}\), and the change \(\Delta K_{\text{tot}}\).

  4. Using the system energy balance \(W_{\text{ext, real}}=\Delta K_{\text{tot}}+\Delta U_{\text{int}}\), determine \(\Delta U_{\text{int}}\) and explain its physical meaning in this scenario.

  5. In one or two sentences, explain why \( \Delta K_{\text{cm}} \ne \Delta K_{\text{tot}} \) in this problem even though \(V_{\text{cm}}\) is constant.

# CM vs System Work–Energy (Inelastic Collision) — No Calculus, No Springs
# Two carts on a frictionless track collide inelastically (stick together).
# We compare the CM pseudo work–energy (ΔK_cm) to the full system energy change (ΔK_tot).

from dataclasses import dataclass
import math

@dataclass
class Cart:
    m: float  # mass [kg]
    v: float  # velocity [m/s] (+ to the right)

# --- Given values (edit to create variants) ---
cart1 = Cart(m=1.0, v=+3.0)   # m1 = 1.0 kg, v1i = +3.0 m/s
cart2 = Cart(m=2.0, v=-1.0)   # m2 = 2.0 kg, v2i = -1.0 m/s

# ---------- Helper functions ----------
def fmt(x, sig=4):
    """Friendly number formatting (scientific if very big/small)."""
    if abs(x) < 1e-15:
        return "0"
    exp = int(math.floor(math.log10(abs(x))))
    if -2 <= exp <= 3:
        return f"{x:.{sig}g}"
    return f"{x:.{sig-1}e}"

def line(w=62): 
    return "-" * w

# ---------- Core computations ----------
# Total mass
M = cart1.m + cart2.m

# Initial total momentum and CM speed (no horizontal external impulse -> CM speed constant)
P_i = cart1.m * cart1.v + cart2.m * cart2.v
V_cm_i = P_i / M
V_cm_f = V_cm_i

# CM kinetic energy (same before and after because V_cm is constant)
K_cm_i = 0.5 * M * V_cm_i**2
K_cm_f = 0.5 * M * V_cm_f**2
delta_K_cm = K_cm_f - K_cm_i  # should be ~ 0

# Perfectly inelastic collision -> common final speed equals CM speed
v_f = V_cm_f

# Total kinetic energy before/after
K_tot_i = 0.5 * cart1.m * cart1.v**2 + 0.5 * cart2.m * cart2.v**2
K_tot_f = 0.5 * M * v_f**2
delta_K_tot = K_tot_f - K_tot_i

# System energy balance with no horizontal external work:
# 0 = ΔK_tot + ΔU_int  -> ΔU_int = -ΔK_tot
delta_U_int = -delta_K_tot

# ---------- Output ----------
print(line())
print("CM vs System Work–Energy (Inelastic Collision) — Results")
print(line())
rows = [
    ("Total mass M [kg]", M),
    ("Initial total momentum P_i [kg·m/s]", P_i),
    ("V_cm initial [m/s]", V_cm_i),
    ("V_cm final [m/s]", V_cm_f),
    ("K_cm initial [J]", K_cm_i),
    ("K_cm final [J]", K_cm_f),
    ("ΔK_cm [J]", delta_K_cm),
    ("Common final speed v_f [m/s]", v_f),
    ("K_tot initial [J]", K_tot_i),
    ("K_tot final [J]", K_tot_f),
    ("ΔK_tot [J]", delta_K_tot),
    ("ΔU_int (from system balance) [J]", delta_U_int),
]
for name, value in rows:
    print(f"{name:<38} : {fmt(value)}")
print(line())

# Sanity check: ΔK_cm should be numerically ~ 0
if abs(delta_K_cm) < 1e-12:
    print("Check: ΔK_cm ≈ 0 as expected (no change in CM motion).")
else:
    print("Warning: ΔK_cm not ~ 0. Recheck inputs/assumptions.")

# ---------- Energy "blop" explanation ----------
print(" ")
print("Energy Interpretation:")
print("  ΔU_int represents the energy that used to be organized kinetic motion")
print("  but is now stored internally within the joined carts.")
print("  During the collision, surfaces deform and vibrate; those vibrations")
print("  become heat, sound, and tiny residual oscillations.")
print("  Total energy is still conserved — it has just changed form:")
print("    Initial Kinetic Energy  →  Final Kinetic + Internal (heat/sound)")
print("  In this problem:")
print(f"    Lost kinetic energy: {fmt(-delta_K_tot)} J  →  internal energy increase of {fmt(delta_U_int)} J.")
print(line())
